### About Sequins


Sequin (SEQUIN) are a reward token distributed based on the value and age of coins users have already hold. 


The CashToken category id for Sequins is:


[{ sequinCat }](https://explorer.salemkode.com/token/{sequinCat})


The Sequins vault can only release tokens based on the age of the vault thread or coin being used (whichever utxo is younger). The vault can release tokens at a rate of 512 Sequin per coin per second. Users with that don't have a whole coin can claim rewards at the same rate as user with many blocks.

Anytime coins are moved, the age of the coin resets. So don't move coins to claim Sequins, wait until you can sign with the wallet you have.
