# About Photons

Photon tokens are a fairly distributed minable (sha256) CashToken creating a decentralized energy oracle. 



Anyone can utilize excess electricity to work to emit Photons (PHOTON) from the vault contract. Photons are released from the vault when someone finds the hash of the transaction is below a certain difficulty threshold. The vault contract also allows anyone to use the price baton for a fee (8000 sats).
